
# TMA3084 Software Engineering Lab 1
## Pizza Order Calculator

This project is a simple Dart console program that calculates the total payment for pizza orders.

### Pizza Prices
- Small: USD 5.00
- Medium: USD 7.00
- Large: USD 10.00

### Program Requirements
- Imports the `dart:io` library.
- Accepts pizza size and quantity from the user.
- Uses a `switch` statement to calculate the total payment.
- Uses `while` loops for continuous ordering and input validation.
- Displays the total payment for each order.

### How to Run
Run the program using the following command:

`dart run main.dart`
